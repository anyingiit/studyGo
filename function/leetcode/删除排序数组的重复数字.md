### 解题思路
1. 长度为零直接返回
2. 设定真实长度计数为1, 因为长度不为零就至少为1
3. 循环sum, 如果当前元素不等于后面的元素,则ralLen+1, 并且该数按照ralLen替换
4. 按照ralLen截取sum

### 代码

```golang
func removeDuplicates(nums []int) int {
    if len(nums) == 0 {
        return 0
    }
    var ralLen = 1 //既然长度不为零就至少为1
    for i:=0;i<len(nums)-1;i++{
        if nums[i] != nums[i+1]{
            ralLen++
            nums[ralLen-1] = nums[i+1]
        }
    }
    nums = nums[:ralLen]
    return len(nums)
}
```
