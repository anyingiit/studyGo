### 解题思路

1. 记录坐标,后置零
   1. 遍历整个数组, 获取值为0的坐标, 并将坐标加入target
   2. 遍历target
      1. 根据matrix的排长度循环,将坐标目标处的整排进行置0
      2. 根据matrix的列长度循环,将坐标目标处的整列进行置0
   3. 完成

### 代码

```golang
func setZeroes(matrix [][]int) {
	var target [][]int //{{排,列},{排,列},{排,列}....}
	for i := 0; i < len(matrix); i++ {
		for j := 0; j < len(matrix[i]); j++ {
			if matrix[i][j] == 0 {
				target = append(target, []int{i, j})
			}
		}
	}
	for i := 0; i < len(target); i++ {
		for k := 0; k < len(matrix[target[i][0]]); k++ {
			matrix[target[i][0]][k] = 0
		}
		for l := 0; l < len(matrix); l++ {
			matrix[l][target[i][1]] = 0
		}
	}

}
```
