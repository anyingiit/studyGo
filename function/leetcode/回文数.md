### 解题思路
1. 如果x为负数直接返回false
2. 转为string
3. 循环string, 只要发现倒序和正序有一个位置数不一样就返回false
4. 返回true

### 代码

##### 执行100方法
```golang
func isPalindrome(x int) bool {
	if x < 0 {
		return false
	}
	xStr := strconv.Itoa(x)
	for i, _ := range xStr {
		if !(xStr[len(xStr)-1-i] == xStr[i]) {
			return false
		}
	}
	return true
}
```

##### 笨方法

```golang
func isPalindrome(x int) bool {
	if x < 0 {
		return false
	}
	tmp := x
	target := 0
	for x != 0 {

		target = target*10 + x%10
		x /= 10
	}
	if tmp == target {
		return true
	}
	return false
}
```
